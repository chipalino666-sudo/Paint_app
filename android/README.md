# Лонжерон для Android

Приложение-оболочка вокруг сайта `https://ceh-lonjeron.ru`:
свой значок, без адресной строки браузера, с загрузкой фото и скачиванием документов.

## Что внутри

- Открывает сайт на весь экран, запоминает вход (куки живут между запусками).
- Ссылки `tel:`, `mailto:`, WhatsApp, Telegram — открываются в своих приложениях.
- Документы ТДС и паспорта (PDF) — скачиваются в «Загрузки» телефона.
- Выбор фото и съёмка на камеру — через системный выбор файла.
- Кнопка «Назад» листает историю страниц, а не закрывает приложение.
- Нет интернета — надпись «Нет связи», нажатие пробует снова.

## Сборка

Нужны JDK 17 и Android SDK (platform 34, build-tools 34). Android Studio и Gradle не нужны.

```
C:\AndroidBuild\jdk-17.0.21.1+2
C:\AndroidBuild\sdk
```

```
powershell -ExecutionPolicy Bypass -File C:\DeepSeek\Deep2\android\build-apk.ps1
```

Результат: `build\lonjeron.apk` (около 45 КБ).

## Подпись

Первый запуск сборки создаёт ключ `Lonjeron\lonjeron.keystore`
(alias `lonjeron`, пароль `lonjeron2026`). **Этот файл надо хранить**: обновления
приложения должны быть подписаны тем же ключом, иначе Android откажется их ставить
поверх старой версии.

## Версия

Версия задаётся в `Lonjeron\AndroidManifest.xml`:

```
android:versionCode="1"
android:versionName="1.0"
```

При выпуске обновления увеличивайте `versionCode` (2, 3, …), иначе телефон
посчитает APK «той же версией».

## Установка на телефон

1. Открыть на телефоне `https://ceh-lonjeron.ru/downloads/lonjeron.apk`
   (или в программе: меню пользователя → «Приложение для Android»).
2. Разрешить установку из этого источника.
3. Открыть APK → «Установить».

## Ограничение Android WebView

В приложении **не работает голосовой ввод** через кнопку микрофона в интерфейсе:
Android WebView не поддерживает Web Speech API (в браузере Chrome — работает).
Микрофон на клавиатуре (Gboard) при этом работает как обычно.
