CRM малярного цеха

Внутренний портал малярного цеха. Доступ только для сотрудников — логин и пароль выдаёт администратор.

Скачать приложение для Android · 73 КБ
Android (Chrome): меню ⋮ справа вверху → «Установить приложение»
iPhone (Safari): кнопка «Поделиться» → «На экран «Домой»»
Компьютер: значок установки в адресной строке

Важно: открывать нужно в обычном браузере, а не по ссылке внутри мессенджера — встроенные браузеры приложения не устанавливают.
