Установить приложение

Программа откроется в своём окне — без адресной строки и вкладок, как обычное приложение. Вход и данные остаются прежними.

Телефон Android (Chrome): меню ⋮ → «Установить приложение»
Телефон iPhone (Safari): кнопка «Поделиться» → «На экран «Домой»»
Компьютер (Chrome, Edge): значок установки справа в адресной строке
