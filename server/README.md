# Малярный цех — серверная версия

Общая база для цеха: заказы, машины, мастера, списание материалов, отчёты.
Ноль внешних зависимостей — работает на голом Node.js.

---

## Запуск без командной строки

На рабочем столе лежит ярлык **«Малярный цех»**. Двойной щелчок:

1. запускает сервер в фоне, если он ещё не работает;
2. открывает программу отдельным окном — без вкладок и адресной строки.

Интернет не нужен: всё работает на этом компьютере.

| Файл в корне проекта | Зачем |
|---|---|
| `launch.vbs` | то, что запускает ярлык (без мелькания консоли) |
| `launch.ps1` | проверяет, поднят ли сервер, запускает и открывает окно |
| `stop-server.cmd` | остановить сервер, если понадобится |
| `app.ico` | иконка программы и ярлыка |

Закрытие окна программы **не останавливает** сервер — можно открыть заново
двойным щелчком, данные на месте. Полностью выключить — `stop-server.cmd`.

Если сервер не поднялся, ярлык покажет окно с ошибкой, а подробности будут
в `server/data/server.err.log`.

## Запуск вручную

Нужен **Node.js 22.5 или новее** (внутри используется встроенный SQLite).

```bash
cd server
node server.js
```

Откройте **http://localhost:3000**.

Первый вход: логин `admin`, пароль `admin12345`. **Сразу смените пароль** —
кнопка «Выйти» рядом показывает, под кем вы вошли; пароль меняется запросом
`POST /api/me/password` (экран смены пароля появится на следующем этапе).

Сменить пароль первого администратора можно и до первого запуска:

```bash
PAINT_ADMIN_LOGIN=boss PAINT_ADMIN_PASSWORD=секрет node server.js
```

## Доступ с других компьютеров

Сервер слушает все интерфейсы. С другого компьютера или телефона в той же сети:

```
http://192.168.0.10:3000
```

Адрес сервера — `ipconfig` на машине, где он запущен. Если не открывается,
разрешите Node.js в брандмауэре Windows (частная сеть).

## Где данные

`server/data/paint.db` — вся база одним файлом.

**Резервная копия** — просто скопировать этот файл, когда сервер остановлен
(или средствами SQLite: `.backup`). Файлы `paint.db-wal` и `paint.db-shm` —
рабочие, копировать их отдельно не нужно.

## Доступ с телефона

1. Запустите программу (ярлык на рабочем столе).
2. Один раз запустите в папке проекта **«Доступ с телефона.cmd»** — он спросит
   разрешение администратора, откроет порт 3000 в брандмауэре и покажет адрес.
3. На телефоне откройте этот адрес в браузере, например `http://192.168.3.10:3000`.

Телефон и ноутбук должны быть в одной сети: либо оба в Wi-Fi цеха, либо ноутбук
подключён к точке доступа телефона.

Адрес может измениться после переподключения к другой сети — просто запустите
«Доступ с телефона.cmd» ещё раз, он покажет актуальный.

Если телефон не открывает страницу: проверьте, что брандмауэр пропускает порт
(скрипт это делает) и что в сети нет изоляции клиентов. На точке доступа
телефона её обычно нет.

## Внутренний чат

Раздел **«Обсуждения»** — общий канал цеха, плюс отдельное обсуждение в карточке
каждого заказа. Сообщения хранятся в базе и **не удаляются**: это история
договорённостей, к ней всегда можно вернуться.

Непрочитанные показываются цифрой на пункте меню. Обновление — раз в 5 секунд.

## Рабочее место мастеров (один компьютер на несколько человек)

У мастеров общий компьютер, поэтому вход сделан в два шага:

1. Компьютер входит под общей учётной записью с ролью **«Рабочее место мастеров»**
   (пароль знают все мастера).
2. Дальше на экране — **ПИН-код из четырёх цифр**. Каждый вводит свой и попадает
   в личный кабинет: свои заказы, своё списание, своё «Готово».

**ПИН — не пароль.** Он нужен, чтобы случайно не начать работу в чужом кабинете,
а не чтобы закрыть доступ. Поэтому:

- никаких блокировок за неверные попытки нет;
- любой мастер может войти под любым ПИНом — например, чтобы доделать или
  закрыть заказ за коллегу, которого нет на месте.

Через **10 минут бездействия** кабинет закрывается сам и снова просит ПИН
(настраивается переменной `PAINT_IDLE_MINUTES`). Кнопка **«Сменить мастера»**
в шапке закрывает кабинет сразу.

ПИН задаётся в разделе **«Сотрудники»** — кнопка «Задать ПИН». Четыре цифры,
одинаковых быть не может: иначе система не поймёт, кто вошёл.

## Роли

| Роль | Что может |
|---|---|
| `admin` | всё + сотрудники |
| `manager` | заказы, машины, мастера, прайс, отчёты, печать |
| `master` | видит только свои заказы, списывает материал, сдаёт «Готово» |
| `store` | видит все заказы и отчёты, печатает бланки |
| рабочее место | общий вход для компьютера мастеров, сам по себе ничего не делает — только открывает кабинет по ПИНу |

### Маляр и кузовщик

Мастера делятся на две специальности (поле `specialty` у пользователя):

- **маляр** (`painter`) — работает как раньше: свой кабинет по ПИНу, списание
  материалов, «Готово»;
- **кузовщик** (`bodyworker`) — пока заглушка: его можно назначить на заказ,
  но своего кабинета и ПИНа у него нет.

В заказе два исполнителя: `master_id` (маляр) и `bodyworker_id` (кузовщик).
Оба видны в карточке и в списке, изменения попадают в историю.

## Автозапуск на Windows

Проще всего — «Планировщик заданий»: задание «При входе в систему», программа
`node.exe`, аргументы `server.js`, рабочая папка `C:\путь\к\server`. Для запуска
как службы (без входа в систему) удобен NSSM.
