# Заказ-наряд малярного цеха

Небольшое приложение для быстрого составления бланка материала: поиск по базе,
две таблицы (автоэмаль и материалы), шаблоны готовых красок с автоматическим
пересчётом миксов и печать в PDF.

Работает и на компьютере, и на телефоне — это одна и та же страница, которая
сама подстраивает вид под ширину экрана.

**Открыть:** https://chipalino666-sudo.github.io/Paint_app/

## Что нового

### 🧪 Шаблоны готовых красок — главное

Раньше, списывая готовую краску, приходилось вручную добавлять каждый микс и его
количество. Теперь состав заводится один раз, а дальше вы выбираете название и
указываете объём — программа сама считает и добавляет миксы в бланк.

Пример: шаблон «Lada 221», состав на 100 г — 62 г одного микса и 38 г другого.
В бланке указываете 350 г — программа добавит 217 г и 133 г.

Точность расчёта — **0,01 г**.

**Как создать шаблон:**

1. Переключитесь на вкладку «🎨 Готовые краски» над строкой поиска.
2. Нажмите «＋ Новая краска».
3. Введите название готового цвета (например, `Lada 221`).
4. Укажите базу состава — то количество, на которое вы знаете рецептуру
   (обычно 100 г; можно 1 кг — тогда в графах миксов пишите граммы на килограмм).
5. В поле «Добавить микс» начните вводить код или название — выберите нужный
   материал из подсказки и укажите его количество.
6. Когда сумма миксов сойдётся с базой, подсказка станет зелёной. Нажмите
   «Сохранить».

Изменить или удалить краску — кнопка ✎ на её карточке.

**Как использовать:** переключитесь на вкладку «🎨 Готовые краски» над строкой
поиска и наберите название. Без запроса список показывает все ваши цвета.
Впишите нужное количество (по умолчанию подставляется база) и нажмите
«→ В бланк». Под полем сразу видно, сколько чего получится.

Поиск понимает и коды миксов: запрос `570` покажет все цвета, в которые входит
этот пигмент.

Материалы и готовые краски ищутся отдельно, в разных режимах — они не
смешиваются в одном списке, как раньше.

Если добавить одну и ту же краску дважды, миксы не задублируются — количество
сложится.

### ⭐ Часто используемые материалы

Программа запоминает, что вы берёте чаще всего, и показывает это первым делом,
пока строка поиска пустая. Самые ходовые материалы оказываются в один клик, без
поиска.

### 🗂 Категории

Под поиском появились фильтры: краски, грунты, шпатлёвки, лаки, абразивы,
растворители, отвердители, расходники, прочее. Можно смотреть всю категорию
списком, не набирая запрос.

### ⬇️⬆️ Перенос шаблонов между устройствами

Кнопки «⬇ Копия» и «⬆ Загрузить» в режиме «Готовые краски» сохраняют и
загружают базу красок файлом `.json`. Так рецептуры можно перенести с
компьютера на телефон (и обратно), а заодно сделать резервную копию.

Вместе с шаблонами в файл попадает история «часто используемых материалов» —
на новом устройстве список самых ходовых не придётся набирать заново.

При импорте шаблоны с уже существующими названиями не дублируются.

### Исправлено

- Одинаковые материалы больше не плодятся отдельными строками — количество
  складывается.
- Названия с кавычками больше не ломают вёрстку бланка.
- Поиск работает с одного символа, а не с двух.
- Подсказка «Сохранить как PDF» больше не попадает в сам PDF.
- Галочка «Очищать поиск при добавлении» запоминается.
- Код разложен на понятные файлы вместо одной длинной строки.

## Ограничения

**Данные хранятся в браузере того устройства, где вы работаете.** Облачной
синхронизации нет: шаблоны, заведённые на компьютере, не появятся на телефоне
сами. Для переноса используйте «Экспорт» → «Импорт».

Если очистить данные браузера, черновик бланка и шаблоны пропадут — поэтому
периодически делайте «Экспорт».

Приложение напоминает об этом само: в режиме «Готовые краски» над списком
висит жёлтая полоса, пока в файл не выгружена свежая копия, — с кнопкой
«Скачать копию». После экспорта она становится серой и показывает дату копии.

Приложение не устанавливается на телефон как обычное приложение: это страница,
открытая в браузере. Ярлык на рабочем столе — самый простой способ запуска.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы |
| `styles.css` | Стили, включая мобильный вид и правила печати |
| `app.js` | Вся логика: поиск, бланк, шаблоны, экспорт, печать |
| `database.js` | База материалов (473 позиции): код и название |
| `categories.js` | Категория для каждого кода из базы |
| `recipes.js` | Шаблоны «по умолчанию» — заготовка для общего справочника |

### Как добавить материал в базу

Откройте `database.js` и добавьте строку в список:

```js
{ code: "SE000000", name: "Название материала" },
```

Затем допишите его категорию в `categories.js`:

```js
"SE000000": "paint",
```

Если категорию не указать, материал попадёт в «Прочее» — работать будет, но
фильтр его не найдёт.

### Как запустить локально

Достаточно открыть `index.html` в браузере. Для проверки на телефоне в той же
сети удобнее поднять локальный сервер:

```bash
npx serve .
```

## Технические заметки

- Никаких зависимостей и сборки: чистый HTML/CSS/JS, обычные `<script>`.
- Хранение — `localStorage`: ключи `paintShopFormData`, `paintShopRecipes`,
  `paintShopUsage`, `paintShopClearToggle`.
- Миксы считаются как `amount * (volume / base)` с округлением до 0,01 г.
- Печать — через `window.print()`, разметка под А4, две колонки.
